## Important Note

Despite the strengths of this architecture, I am discontinuing this framework.  
Both Loopback and **Next.js**—even though powerful—present challenges that make them less suitable for large‑scale enterprise systems.

### Key Issues

- **Breaking updates** in both Loopback and **Next.js** occur frequently.  
- Loopback’s lack of **compound primary key support** limits database normalisation beyond 3NF, making 4NF and 5NF difficult and reducing performance‑tuning options for large datasets.
- While TypeScript enables unified development across APIs, web apps, and mobile apps (React/**Next.js** + Loopback), the same benefits exist in the more mature and secure **.NET ecosystem**.

### Why .NET Is a Better Fit

Using **Blazor (C#)** and **MAUI (C#)** provides:

- A cohesive, strongly‑typed, enterprise‑ready environment  
- Better tooling  
- Better AI library support  
- Greater long‑term stability  

That said, **Loopback with TypeScript still offers excellent features**, and this project remains a valuable demonstration of architectural patterns, extensibility, and full‑stack TypeScript workflows.
